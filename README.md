# 晋见山乡 · 山西乡村记忆计划

面向“乡村振兴·科创赋能”作品赛道的静态交互原型。用真实开放地图、故事档案、语音体验、实地路线、三维村落模型和本地共创草稿，展示乡村文化数字化保护与传播的可能性。

## 打开方式

直接打开 index.html，无需安装或构建。真实地图底图来自 OpenStreetMap，加载地图时需要联网；其他页面内容与插画保存在本地。建议在较新的 Chrome、Edge 或 Firefox 中体验 3D WebGL 场景与中文语音合成。

## 独立页面

- 首页：项目概览、精选故事入口和功能导览。
- 山西地图：OpenStreetMap 真实底图，覆盖山西省全域；可切换 11 个地级市中心定位。
- 故事档案：五类主题、50 条线索，支持分类、搜索、分页、详情与收藏。
- 田野图像图鉴：五组生成图像、60 个独立画面，支持分类筛选、分页和单张放大。
- 记忆时间轴：拖动年代筛选情境样稿。
- 乡音档案：浏览器语音合成朗读、播放队列、语速和同步文字。
- 乡野漫游：三条区域采录路线提案，可跳到真实地图中的城市级入口。
- 3D 村落：原生 WebGL 建模，可拖动旋转、缩放、重置视角、点击 3D 节点进入故事。
- 共创工坊：文字线索、地点和年代草稿，照片与麦克风本地预览，草稿 JSON 导出；不上传数据。
- 我的收藏：浏览器本地书签。
- 采录指南：讲述者授权、坐标校对、方言记录和图片权利的工作提示。

## 内容边界

11 个城市入口和城市中心坐标用于全省地图导航。故事文字为展陈结构体验用的情境样稿，路线为走访策划提案，村级地名和点位尚未采录核验；3D 场景是文化空间概念模型，不代表任何具体村庄的实测成果。正式参赛或发布前，请补充真实村庄合作、采访授权、实测坐标、史实校对与素材来源。
